# mini-agent：从零手写的一个极简 ReAct Agent

一个不依赖任何 Agent 框架、用 **Python + DeepSeek API + 原生 function calling** 从零写出来的极简 Agent。代码量很小（200 行左右），重点是把 Agent 的核心原理完整走通一遍。

## 功能

- **3 个工具**：`calculator`（计算器）、`get_time`（查时间）、`get_weather`（模拟查天气）
- **多轮对话**：连续提问不中断，能记住之前聊过什么
- **上下文管理**：对话超长时自动截断最旧消息，永远保留系统提示
- **行为可观测**：每次工具调用都有日志打印——模型"想调什么工具、传了什么参数、工具返回了什么"一目了然

## 技术栈

Python · DeepSeek API（OpenAI 兼容模式）· function calling

## 文件说明

| 文件 | 说明 |
|---|---|
| `mini_agent.py` | 单轮版：3 个工具 + 工具分派主循环 |
| `mini_agent_v2.py` | 升级版：多轮对话 + 上下文记忆 + 超长截断 |

## 快速开始

```bash
# 1. 安装依赖
pip install openai

# 2. 获取 DeepSeek API Key（platform.deepseek.com），充值 10-20 元即可

# 3. 把脚本里的 api_key 替换成你自己的 Key

# 4. 运行
python mini_agent_v2.py
```

> ⚠️ 不要把真实 API Key 提交到 GitHub。本仓库里的 key 已替换为占位符，请换成你自己的。

## 我是怎么从 0 到 1 把它写出来的

背景：双非大二计算机本科生，大一没怎么学，底子和非科班差不多。写这个 Agent 不是为了炫技，而是在大环境焦虑下，用"**做出来一个东西**"代替"学完一堆课"。

**我的方法：抄写。** 对着代码一行一行打、一行一行理解，比坐着干瞪眼、看几十小时超长网课有效得多。

### 三个前置知识（缺一不可）

1. **Agent 核心循环**：思考（Thought）→ 行动（Action）→ 观察（Observation）→ 再思考。用户提问 → 思考需要什么工具 → 调用工具 → 看返回结果 → 信息不够就再来一轮，够了就回答。
2. **ReAct**：推理（Reasoning）+ 行动（Acting）结合，让模型边想边做。
3. **function calling**：定义工具函数 → 把"工具说明书"（名字/描述/参数格式）发给模型 → 模型决定调用哪个 → 程序执行 → 结果回喂模型，模型判断信息够不够。

### 实践节奏

先让 AI 给出代码框架，然后**分模块自己敲**：先敲工具函数，看不懂就问；理解了再敲工具说明书；最后写主循环。全部敲完，检验自己能不能解释清楚每一行在干什么、为什么这么干，最后调试。

### 踩过的坑

- **TypeError**：`messages` 里 append 了 API 返回的**对象**而不是字典，遍历时报 `ChatCompletionMessage object is not subscriptable`——用 `model_dump()` 转成字典解决。
- **缩进错误**：`for` 循环少一个空格，Python 直接报 `IndentationError`。
- **模型偷懒**：大模型有时不调工具、直接照着历史编答案（天气、时间都是编的）——加打印日志让行为可见，一眼识破。

### 做完的感受

Agent 并不神秘，本质就是"**模型 + 工具 + 循环**"；但工程上处处是细节（上下文管理、类型转换、幻觉防护），只有自己踩一遍才记得住。
